## `belief-convergence.svg`

Original teaching graphic generated by `scripts/generate-bayes-filter-figures.py`
using NumPy and Matplotlib. No external data, images, or font requests.
The script checks the measurement sequence and both worked examples before plotting.
It retains full precision for computation and labels the plotted values to three decimals.
The plot includes step 0 (the initial prior) and all eight measurement updates.
Its embedded dark-mode palette follows the existing `Figure` color-scheme rules.

Regenerate from the repository root:

```sh
python -m venv /tmp/bayes-filter-venv
/tmp/bayes-filter-venv/bin/pip install numpy matplotlib
/tmp/bayes-filter-venv/bin/python scripts/generate-bayes-filter-figures.py
```

Generated with NumPy 2.5.5 and Matplotlib 3.11.2. Dependencies are authoring-only;
the website needs no new runtime packages. Versions may affect SVG serialization.

## Intuition-builder visuals

Six additional original illustrations are generated by
`scripts/generate-bayes-intuition.py`, then embedded with the existing `Figure`
component in both lesson locales:

| Asset | Lesson placement | What it shows |
| --- | --- | --- |
| `airplane-conditional.svg` | Section 1, hook | The same jet before and after observing two engine fires; the baseline statistic remains explicitly qualified. |
| `shrinking-universe.svg` | Section 1, conditional probability | Joint overlap within the sample space versus the same relative overlap within Z alone. Areas are schematic. |
| `markov-timeline.svg` | Section 2, Markov assumption | State, control, and measurement dependencies, with old history faded and departure-state action indexing preserved. |
| `normalization.svg` | Section 4, first hand calculation; linked from Section 3 | Stacked scores totaling 0.70 stretched to total 1.00, with the 9:5 ratio preserved. |
| `elementwise-update.svg` | Section 4, Python update | The selected likelihood row and the matching prior entries produce one score per state; this is not matrix multiplication. |
| `action-comparison.svg` | Section 5, action versus measurement | Matplotlib grouped bars for prior, prediction, and posterior on both tracks. No action leaves the prediction at 0.500. |

Regenerate with the same authoring environment as the convergence plot:

```sh
/tmp/bayes-filter-venv/bin/python scripts/generate-bayes-intuition.py
```

The first five are hand-authored SVG geometry serialized by Python; the comparison
is plotted with Matplotlib from the model, not hardcoded rounded results. The
script verifies the normalization ratio and both comparison tracks. All six
assets are self-contained, have accessible SVG titles/descriptions and lesson
alt text, and use light/dark palettes through the existing `Figure` color-scheme
rules. Labels and captions supplement color. Matplotlib text is converted to
paths to avoid font-dependent clipping; dates are omitted and SVG ID salts are
fixed for repeatable generation. No third-party media are used in these six illustrations.

**Index convention:** action uₜ starts at state xₜ and leads toward xₜ₊₁.
Consequently the highlighted incoming action for xₜ is uₜ₋₁, not uₜ. A true
Markov state summarizes relevant history, but the filter must retain a belief
over it rather than assuming that state is known. The action comparison shows
one example of higher open probability, not a guarantee that actions always
reduce uncertainty or that more confidence proves a correct estimate.

## Navigation and notation

The existing catalog discovers `bayes-filter/en.mdx` automatically. Frontmatter
`order: 2` places it after Intro to Localization in the Localization group; section
IDs, titles, and chips populate the lesson navigation. No manual registry changes
or new code bundle are needed. The lesson has complete English and Traditional
Chinese versions.

Math intentionally follows Module 1's inline code / `text` fences and Unicode
symbols. The repository does not configure a LaTeX renderer; dollar delimiters
would display literally. The lesson corrects the distinction between Markov
transition models and marginalized beliefs rather than equating them.
