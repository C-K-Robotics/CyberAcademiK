# Types & Schema

CyberAcademiK's content system defines types at three levels of abstraction: the raw build-time data from the Vite plugin, the rendered catalog types used throughout the UI, and the course module types that connect metadata to content loaders.

## Rendered types (`src/content/types.ts`)

These are the types used by all UI components and the discovery layer.

### `CourseEntry`

A course entry in the catalog taxonomy. Every discovered course is available through this type.

```ts
interface CourseEntry {
  slug: string                    // URL slug — folder name, matches /courses/:slug
  title: Localized<string>        // { en: "...", "zh-Hant": "..." }
  desc: Localized<string>         // Short description
  level: Level                    // "beginner" | "intermediate" | "advanced"
  minutes: number                 // Estimated reading/working time
  isNew?: boolean                 // "NEW" badge indicator
}
```

### `CourseGroup`

A subcategory (second directory level under `content/`).

```ts
interface CourseGroup {
  id: string                      // Unique identifier
  name: Localized<string>         // Localized display name
  courses: CourseEntry[]          // Courses in this subcategory
}
```

### `Subteam`

A top-level category (first directory level under `content/`).

```ts
interface Subteam {
  id: string                      // e.g. "mech", "elec", "ctrl"
  icon: LucideIcon                // Resolved icon component from icons.ts
  accent: string                  // CSS custom property name, e.g. "--ac1"
  accentRgb: string               // Comma-separated rgb triple for rgba()
  title: Localized<string>
  blurb: Localized<string>
  tags: Localized<string[]>       // Per-locale tag array
  groups: CourseGroup[]           // Subcategories
}
```

### `CourseMeta`

A course's resolved metadata, built at runtime from per-locale MDX frontmatter.

```ts
interface CourseMeta {
  slug: string
  subteamId: string               // Owning category id
  title: Localized<string>
  kicker: Localized<string>       // Eyebrow label, e.g. "PID CONTROL"
  lead: Localized<string>         // Short eyebrow text above title
  author: string
  minutes: number
  level: Level
  updated: Localized<string>
  references: Localized<Reference[]>
  upNext?: Localized<UpNext>      // Next lesson suggestion
}
```

### `CourseBundle`

Optional course-specific code, auto-discovered from `src/courses/<slug>/index.tsx`.

```ts
interface CourseBundle {
  components: MDXComponents       // Custom MDX components for this course
  Wrapper?: ComponentType<{ children: ReactNode }>  // Optional state provider
}
```

### `CourseModule`

A fully resolved, renderable course combining metadata, content loaders, and optional bundle.

```ts
interface CourseModule {
  meta: CourseMeta
  components: MDXComponents
  Wrapper?: ComponentType<{ children: ReactNode }>
  content: Partial<Record<Locale, () => Promise<{ default: ComponentType }>>>  // Lazy loaders
}
```

### `Localized<T>`

A helper type for per-locale values:

```ts
type Localized<T> = Record<Locale, T>  // Locale = "en" | "zh-Hant"
```

### Supporting types

| Type | Values |
|------|--------|
| `Level` | `"beginner"` \| `"intermediate"` \| `"advanced"` |
| `Reference` | `{ label: string; href: string }` |
| `UpNext` | `{ label: string; href: string }` |

## Raw types (`src/content/raw.ts`)

These types mirror the on-disk `content/` files exactly — localized fields are plain `Record<string, T>` (no component resolution), everything is plain JSON. These are the shapes emitted by the `virtual:course-catalog` module (generated by `vite/course-content.ts`).

```ts
interface RawCourse {
  slug: string
  categoryId: string
  subcategoryId: string
  order: number
  locales: string[]
  contentPaths: Record<string, string>   // { en: "/content/.../en.mdx", ... }
  title: Record<string, string>
  desc: Record<string, string>
  kicker: Record<string, string>
  lead: Record<string, string>
  updated: Record<string, string>
  references: Record<string, RawReference[]>
  upNext: Record<string, { label: string; href: string }> | null
  author: string
  minutes: number
  level: Level
  isNew: boolean
}

interface RawSubcategory { id: string; order: number; name: Record<string, string>; courses: RawCourse[] }
interface RawCategory { id: string; order: number; icon: string; accent: string; title: Record<string, string>; blurb: Record<string, string>; tags: Record<string, string[]>; groups: RawSubcategory[] }
interface RawCatalog { categories: RawCategory[] }
```

## YAML frontmatter schema

Course frontmatter fields (from MDX files):

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string | Yes | Display title (per locale) |
| `desc` | string | No | Course description |
| `kicker` | string | No | Eyebrow label (e.g. "INTRO TO ROBOTICS") |
| `lead` | string | No | Paragraph above the title |
| `author` | string | No | Author/credit |
| `minutes` | number | No | Estimated time in minutes |
| `level` | string | No | `beginner` | `intermediate` | `advanced` |
| `order` | number | No | Sort position within subcategory |
| `references` | array | No | `{ label, href }` entries |
| `upNext` | object | No | `{ label, href }` for next lesson link |
| `updated` | string | No | Last updated date |
| `isNew` | boolean | No | Show "NEW" badge |
